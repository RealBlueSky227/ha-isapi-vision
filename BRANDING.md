# ISAPI Vision identity

ISAPI Vision uses camera-and-lens artwork with its white and cyan wordmark on a dark background. The original artwork is distributed as `assets/isapi-vision.png`, without creative changes.

Mechanically resized PNGs are bundled under `custom_components/isapi_vision/brand/`: `icon.png` (256×256), `icon@2x.png` (512×512), `logo.png` (256×256) and `logo@2x.png` (512×512). The full composition and wordmark are preserved. Native custom integration branding displays in HA 2026.3 and newer; older supported releases may display a generic icon.

This is an independent community integration, not an official ANNKE, Hikvision or Home Assistant product. Vendor names identify tested hardware and protocol compatibility. Development hardware is ANNKE FCD600, reporting model I51HD and firmware V5.8.10. Physical compatibility with Hikvision-branded cameras has not yet been verified.

The GitHub social preview is assets/social-preview.png (1200×630), mechanically fitted from the existing artwork. Set it manually in repository Settings → General → Social preview if desired. No replacement artwork was generated.
